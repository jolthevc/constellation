# Constellation

Working foundation for an AI-native portfolio of differentiated media properties and a broad, measurable audience distribution graph. Internal ambition: repeatable, relevant reach across audiences and interest communities.

**Operating phase:** manual pilot first, scalable shared intelligence now, agent assistance and portfolio automation only after creative, commercial and operational validation.

## Core principles

1. We build a **portfolio of properties**, not necessarily synthetic human influencers. Formats must be chosen based on audience, evidence and creative viability.
2. Content psychology matters at each stage: attention, retention, fulfillment, sharing, following, trust and relevant commercial action.
3. Audience psychology is researched and tested, never inferred reductively from demographic labels.
4. Separate observed facts, research-backed hypotheses, local experiments and operating decisions.
5. Value and trust matter more than hollow engagement. No fabricated real-world content or false social proof.
6. Human review is required for important creative and publication decisions during the pilot. Automation readiness must be earned.
7. GitHub houses the initial operating knowledge. Large media assets and high-frequency analytics belong in appropriate storage systems later.
