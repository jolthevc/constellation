# Competitive and Inspirational Property Research
Create one dated competitor profile from `../competitor-profile-template.md` per account/reference property. Analyze real public examples and failures, hook/retention/payoff, audience job, observed cultural fit, rights and production mechanisms. Do not invent private metrics or copy distinctive voice, look, scripts or characterization.

Every profile should state what *our original contribution* would be and the evidence for it. Link reusable observations to FMT/HK IDs, audience interest profiles and a proposed test.
