# Format x Hook x Retention x Payoff Selection

The 149-component `catalog.csv` defines presentation, story engines, visual treatment, engagement mode and surfaces. None of these is an automatic viral formula. **Attach an engagement design to each property-format pairing**, linked to its audience psychology and the five-stage standard.

## Composable design recipe
A usable format is:
`FMT presentation + FMT story engine + FMT visual treatment + FMT surface + HK opening family + progression engine + payoff family + optional participation`.

Example 1: faceless investigative clip + mystery narrative + archival/b-roll + vertical video + HK-011 evidence-first + progressive documentation + qualified reveal + no CTA.

Example 2: close-camera comic fictional monologue + recognition humor + natural jump cuts + vertical video + HK-007 micro-frustration + comic escalation + punchline + optional real prompt for audience anecdotes.

Example 3: interiors carousel + visual comparison + professional stills + carousel surface + HK-017 gorgeous visual + progressive design changes + final reveal + legitimate save for reference. No manufactured countdown.

## Per-format research fields (add to deep-dive record)
- Hook candidates (IDs and actual source observations; at least three alternatives when useful)
- First frame / first three seconds for video; first slide / first line for carousels and text
- Sound-off vs sound-on comprehension; caption density
- Expected viewer context and why they stop, stay, feel satisfied, share, save, comment or follow
- Progression and re-hook grammar by plausible duration
- Payoff family and location
- At most one primary intended interaction outcome
- CTA guidance, including “no CTA”
- Property types where tactic would feel forced or cringey
- Availability of real footage, evidence, permissions and AI-generated media disclaimers
- Relevant performance measures and a falsifiable test hypothesis

## R&D: choose efficacy over trends
Test with the property voice, audience, comparable topic and length. Capture failures and successful comparators. Never prescribe arbitrary cuts every N seconds or a mandatory Easter egg / keyword CTA. For silent visual work, consider a beauty-first hook. For fast-paced comedy, the punchline may be the core payoff. For expertise, proof and usefulness tend to matter more than manufactured mystery.
