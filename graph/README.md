# Distribution Graph
The graph connects **properties, actual channel accounts, audience segments, interests, content formats and commercial categories**. It is a planning and measurement model, not a scraped social graph of identifiable people.

Start with `model.md` and empty, schema-only CSVs. Use stable IDs; do not put guesses in measured fields. Initial audience/interest taxonomy is exploratory, so coverage is not measured yet.

## Questions it should eventually answer
- Which interests and viewer contexts do our properties currently serve?
- Which audiences are overrepresented or underserved?
- Which new property adds credible **incremental** exposure?
- Where are overlapping followings useful for frequency, versus redundant?
- Which formats generate organic reach and satisfied followers across multiple communities?
- Which commercial categories fit earned authority, without compromising trust?

## Operating rules
Do not treat sum of followers/impressions as unique reach. Do not infer individual viewer identities or sensitive demographic categories. Only store cohort-level data and the permitted source/methodology. Edge confidence is separate from edge strength.
