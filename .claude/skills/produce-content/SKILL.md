# Produce Content
1. Read applicable property's identity bible, psychology, engagement strategy, content strategy, and `strategy/attention-retention-payoff-standard.md`.
2. Specify audience viewing job and exact promise/payoff. Produce opening candidates in first-frame visual plus spoken/text treatment.
3. Build beat-by-beat progression and meaningful mini-payoffs. Use pacing appropriate to this property, not arbitrary jump-cut frequency.
4. Create script, research citations, shot list, assets, approved voice, technical editing instructions and a natural optional CTA.
5. If making a real content package, allocate ID via `scripts/new_content.py` under the approved property.
6. Evaluate against `operations/creative-approval-gate.md` and `operations/compliance.md`, flag all blocked claims/rights/identity issues for human review.
7. Never publish automatically; leave `publish.yaml` unapproved until real human signoff.
