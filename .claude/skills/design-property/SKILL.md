# Design a Property
1. Read `strategy/north-star.md`, `strategy/portfolio-allocation.md`, relevant audience research, `formats/README.md` and `psychology/retention-and-payoff-playbook.md`.
2. Develop a differentiated position, psychological promise and three original series. Do not default to a photorealistic host or clone competing creators.
3. Propose first-frame style, six brand-specific hook examples, progression structure, actual payoff, natural interaction and return motivation.
4. Build identity, psychology, engagement strategy, production guide, audience and commercial fit using `properties/_template/`.
5. Evaluate quality/production cost and coverage incrementality, separate assumptions from evidence.
6. Present for human launch approval. Only then use `scripts/new_property.py` if explicitly authorized to add the real entity.
