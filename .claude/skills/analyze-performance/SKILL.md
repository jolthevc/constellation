# Analyze Performance
1. Read `performance/metric-definitions.md`, `performance/engagement-testing.md`, property content briefs and recorded snapshots.
2. Identify platform-specific metric definitions, time windows, organic versus paid distribution and missing data.
3. Diagnose why viewers may stop/stay/drop/rewatch/share/save/follow using measured evidence and qualitative feedback.
4. Compare reasonably similar posts; mark correlations and confounders; do not assert causal effects from a few observational posts.
5. Produce an accountable weekly or content review with hypotheses, exact next creative tests and any trust/quality concerns.
6. Propose updates to shared format/psychology knowledge only if evidence supports the claim. Human approves core brand changes.
