# Agent Orientation: Constellation

This repository provides the **manual-first operating system** for an AI-native portfolio of differentiated media properties. Its ultimate ambition is a measured distribution graph across many audiences and interests, not a factory of identical AI talking heads. Read [README.md](README.md) first and [architecture.md](architecture.md) for system boundaries.

## Core requirements for ALL properties and content
1. Define the audience's **specific psychological job**; avoid rigid demographic stereotypes and hidden personal profiling.
2. Use a recognizable property identity and format mix chosen for quality, audience fit and production economics. Never default to generic synthetic human videos.
3. For every property write an explicit `engagement-strategy.md`: approved hook families, first-frame grammar, retention, mini-payoffs, final satisfaction, organic share/save/comment/follow triggers and off-brand boundaries.
4. For every content item use an approved `content-brief.md` and show: why stop, why stay, exact payoff, optional natural CTA and why return. Develop alternative opening concepts where meaningful.
5. Preserve source/date/evidence type, alternative explanations and uncertainty. Public views do not prove private retention or demographics.
6. Build original creative work. Never counterfeit real interviews, product tests, firsthand stories, social proof or likenesses, and never manipulate engagement.
7. Current pilot is **human-approved**. Research/drafts allowed within authorized tools; no autonomous publishing, account creation, spend or fundamental identity edits.
8. GitHub stores text, schemas and lightweight data. Do not commit credentials, user personal data or raw media libraries.
9. Stable IDs (SEG, INT, FMT, HK, PROP, CHAN, CNT, EXP) and normalized CSV/YAML keep future migration viable. Run `python scripts/validate_repo.py` after changing tracked data.
10. Changes to core bibles, safety constraints and strategy require owner review; do not treat an agent's own PASS label as a publishing authorization.

## State now
Foundation, templates and simple local helpers exist. There is no real pilot property in the registry, and no live data or automatic workflows. Never invent these to make the system appear complete.

## Outputs
Make changes concise, evidenced and versioned. Point to exactly which property/source/experiment supports a claim. Recommend the smallest next experiment that could falsify the strongest uncertainty.
