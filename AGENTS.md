# Agent orientation for Constellation

This is a manual-first, future-agent-assisted system for building an AI-native media portfolio and measurable distribution graph. Read `README.md` first.

## Current usable knowledge
- `formats/README.md`: modular content taxonomy and research method
- `formats/catalog.csv`: candidate format building blocks
- `formats/format-template.md`: source-backed format research record template
- `psychology/framework.md`: why audiences watch, share, follow, trust, and act
- `psychology/mechanisms.yaml`: controlled mechanism tags
- `psychology/content-scorecard.md`: content quality and psychology gates
- `audiences/_template/psychology.md`: segment research
- `properties/_template/psychology.md`: property relationship contract

## Operating rules
1. Do not default to photorealistic AI hosts. Consider faceless, editorial, animated, real footage, synthetic, audio-led, still and programmatic visual methods on equal footing.
2. Every creative recommendation identifies target audience, property purpose, selected format component IDs, intended viewer value, feasibility, and quality constraints.
3. Treat psychological mechanisms as hypotheses. Cite observations and research; preserve dissent and uncertainty. Do not infer personal attributes or stereotypes from demographics.
4. Favor original content and genuine relationships. Never recommend fake engagement, undisclosed sponsors, fabricated testimony, or passing off synthetic footage as real reporting.
5. Do not auto-publish or rewrite fundamental property bibles without explicit authorization.
6. GitHub holds lightweight source-of-truth documents; never commit private credentials or large generated media.
7. Prefer small edits, stable IDs, source links, dated observations and versioned decisions. Preserve validated knowledge rather than overwriting it with impressions.

## Stage
Only the format and psychology foundation has been established so far. The complete portfolio graph, property bibles, measurement pipelines and agents have not yet been built.
