# Content Package Template
Copy to `content/CNT-YYYY-NNN/` and assign a globally stable content ID. Never commit large media files or secrets.

Required files:
- `brief.md`: copy from `properties/_template/content-brief.md`. Name exact hook, progression, payoff, first frame, intended action, sources and rights.
- `script.md`: human-readable narration/dialogue/onscreen text, timing and editorial citations.
- `production.md`: shots, approved tools, asset references, voice/caption timing, sound and review annotations.
- `publish.yaml`: per-channel metadata, disclosure, approvals, output URI, actual published IDs and dates (leave blank until real).
- `review.md`: metric snapshots, limitations, comments, what to test next.

Content ID and property/channel IDs must match portfolio registries. If the piece involves a resource CTA, store proof of existing deliverable and approved delivery flow. Human must approve publishing during pilot.
