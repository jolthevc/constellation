# Identity Bible
Property ID: PROP-XXX | Owner: | Version: 0.1

## One sentence
For [community/psychological job], this distinct media property delivers [recurring benefit] through [recognizable perspective/voice/format].

## Identity and editorial promise
Naming and handle conventions; audience-facing tagline; point of view; what this property believes, questions or finds funny; boundaries and expertise; how it differs from actual competitors.
What a follower can reliably expect; what is explicitly NOT part of the brand.

## Persona, if character-led
**Synthetic / fictional context:** define clearly; don't imply an AI host is a real person.
Canonical appearance: age presentation (if relevant), facial geometry, hair, clothing, signature accessories, proportions, expressions, and physical continuity.
Canonical voice: lawful source, license, accent, timbre, tempo, cadence, rhythm, filler language, pronunciation list, humor, timing and emotional range.
Backstory/fictional world: approved consistent fiction versus actual fact; relationships; recurring situations; forbidden contradictions.
Reference image IDs and voice asset IDs from externally stored approved assets, not binary media in Git.
Allowed actions/places/scenes; resemblance, consent and disclosure constraints.

## If faceless or editorial
Visual design language, type hierarchy, color, graphics, footage treatment, visual pacing, archival citation conventions, narration voice, perspective, recurring transitions, sound language. Authority based on sourced reporting, not invented credentials.

## Social relationship
Audience psychology and emotional promise: see `psychology.md`.
Specific hook, retention, payoff and engagement grammar: see `engagement-strategy.md`.
Tone examples: 6 original on-voice examples and 6 unacceptable off-voice examples.

## Reference and negative reference library
Source URLs, specific admired *mechanism*, reason it works, what we will do differently. Do not imitate distinctive identity or scripts.

## Version rules
Human approves changes to core identity. Log date, reason, references and effect on in-flight production. Minor creative adjustments may be tested under unchanged core identity.
